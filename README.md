# Projet Cinema en JavaScript avec une base de donnees OMDB.
Notre projet est une application web conçu pour le cinéma Le palace qui est le plus grand cinéma du village. Cette application permet aux clients de visualiser les films disponibles.



# Lien du dépôt GitHub: 
`https://github.com/lawsondjeckylaurenne/cinema-OMDB.git`

# Auteur
Laurenne LAWSON-DJECKY en passerelle 3 SUPINFO

# Technologies
HTML, CSS, JavaScript (modules ES), Vite, API OMDb

# Installation pour demarrer le projet:
1. cloner le dépôt
2. Installer les dépendances: `npm install`
3. Copier `.env.example` en `.env` et y mettre une clé OMDb
4. Lancer le serveur: `npm run dev`
